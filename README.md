# ЕГЭ Трекер 1.0

Личный локальный трекер подготовки по профильной математике, русскому языку и информатике. Все семь этапов [TASKS.md](TASKS.md) реализованы.

[Публикация на GitHub Pages](GITHUB-PAGES.md) · [Инструкция пользователя](docs/USER_GUIDE.md) · [Итоговый отчёт](docs/FINAL-REPORT.md)

## Возможности

- Редактируемые номера, необязательные подтемы, быстрые и подробные решения, история со скриншотами и пакетный ввод.
- Взвешенная точность, объём практики, уровень освоения и отдельный срок повторения. Формула версии 1 соответствует `ARCHITECTURE.md`; это эвристика, не прогноз балла ЕГЭ.
- Сводка по всем предметам, поиск и фильтры номеров, приоритет повторений, графики и таблица практики по дням.
- Полные JSON-копии с изображениями, проверка и предпросмотр импорта, подтверждённая атомарная замена и сброс.
- PWA: локальные шрифты и иконки, кеш статических ресурсов, работа после первой загрузки без сети, установка средствами поддерживаемого браузера.

Данные хранятся в IndexedDB текущего браузера. Для переноса между устройствами нужны экспорт и импорт JSON. Рекомендуется регулярно сохранять копии: очистка данных сайта удаляет историю.

## Запуск

Нужен Node.js 22.12+; проект проверен на Node.js 24.

```sh
npm ci
npm run dev
```

Для готовой сборки и проверки PWA:

```sh
npm run build
npm run preview
```

Файлы сборки находятся в `dist/`. Для публикации нужен статический HTTPS-хостинг; localhost подходит для разработки. Маршруты `HashRouter` вида `/#/subjects/math` не требуют серверных перенаправлений. Service worker включён только в production-сборке.

## Архитектура

```text
src/
  app/          маршруты и общий интерфейс
  application/  сценарии, реактивные выборки, время, подготовка изображений и копий
  domain/       сущности, валидация, чистые scoring/review/statistics, формат JSON
  data/         Dexie-схема, каталог, репозитории, транзакции
  features/     страницы, формы, история, графики и резервные копии
  pwa/          манифестная интеграция, офлайн-статус, сборка и service worker
  shared/       компоненты, форматирование и даты
  styles/       Tailwind и адаптивность
 tests/
  e2e/          реальные браузерные сценарии
  fixtures/     отдельная тестовая страница компонентов
```

Основная база `ege-tracker`, версия Dexie 2. Поля и индексы таблиц сохранены; однократное обновление заменяет прежние шаблонные названия заданий на названия из пользовательского списка, сохраняя пользовательские названия и историю. Подробности — [DEFAULT-CATALOG.md](docs/DEFAULT-CATALOG.md). Версия JSON-копии — 1, независима от версии приложения.

Расчёты не хранятся в таблицах. Они пересчитываются из истории при изменении записей, открытии экрана, возвращении вкладки или фокуса; дополнительно проверяются раз в минуту. Для очень старой истории веса масштабируются общим множителем, чтобы избежать численного `0/0`; математически взвешенная точность остаётся той же.

У номера учитываются все его решения; у подтемы — только её собственные. Очередь группирует рекомендации по номеру, показывает причину и вложенные подтемы. Просроченные записи идут первыми, затем учитываются отношение давности к интервалу и слабый уровень. «Нужна практика» в фильтре включает уровни ниже 60/100, включая «Слабая подготовка».

Статистика группирует решения по местным календарным дням браузера, заполняет дни без практики нулевым объёмом и отсутствующей точностью. Процент за период считается из всех решений периода, а не как среднее процентов дней.

## Резервные копии и целостность

Экспорт включает все пять таблиц. UUID и порядок ключей сериализуются детерминированно; Blob превращаются в base64 с MIME и метаданными. Создание копии использует согласованный снимок таблиц в readonly-транзакции.

Импорт сначала проверяет JSON, версию, UUID, поля, даты, уникальность номеров, состав трёх предметов, ссылки, размер и содержимое изображений. После проверки в памяти остаётся подготовленный снимок, связанный с токеном предпросмотра. UI получает только состав и размеры; запись выполняется после отдельного подтверждения. Все таблицы заменяются одной транзакцией. При ошибке, в том числе нехватке места, исходные записи остаются целыми. Слияние копий не поддерживается.

Сброс также транзакционен: возвращает три предмета и стартовый каталог, очищает историю и вложения. Он требует подтверждения и рекомендации заранее сделать копию.

## PWA

Манифест и PNG-иконки 192/512 px входят в сборку. Vite-плагин строит список фактических ресурсов `dist/` и версию кеша по их содержимому. В него входят HTML, JS, CSS, локальные шрифты, иконки и манифест, включая отложенный модуль резервных копий.

Service worker обрабатывает только заранее перечисленные статические пути своего origin. В нём нет пользовательских таблиц, изображений из истории или JSON-экспортов. Для навигации используется сеть с переходом на закешированный интерфейс при недоступности сети. IndexedDB доступна независимо от сети.

Новая версия не прерывает открытую форму: приложение предлагает сохранить её и нажать «Обновить приложение». В настройках показана готовность офлайн-режима. Установка зависит от браузера и системного меню; на iOS обычно используется «Поделиться → На экран Домой».

## Ограничения и принятые решения

- Все ID — UUID; у трёх предметов начальные ID стабильны. Это следует тексту `DATABASE.md`, хотя его сокращённый JSON-пример использует другие обозначения. Исходный документ сохранён.
- Начальные диапазоны: математика №1–19, русский и информатика №1–27. Это нейтральный редактируемый набор, а не утверждённая спецификация ЕГЭ.
- Номер — целое от 1 до 999. Названия — до 120 символов, описание — до 20 000, каждый ответ — до 2 000, комментарий — до 10 000. Управляющие символы отклоняются.
- Один скриншот PNG/JPEG/WebP до 10 МиБ и 40 Мп. Приложение не сжимает изображения без согласия. Несколько вложений потребуют миграции уникального индекса `attemptId`.
- Копия: до 256 МиБ JSON, до 128 МиБ декодированных изображений, до 200 000 сущностей на массив. Превышение выдаёт ошибку без удаления или частичного переноса данных. Импорт не принимает неизвестную версию.
- В статистике можно выбрать 7, 30, 90, 365 дней или свои даты, не более 366 дней за раз. История хранится полностью, независимо от выбранного периода.
- Для предложения результата применяются только NFC и обрезка внешних пробелов. Регистр, ведущие нули, знак, внутренние пробелы и десятичный разделитель не преобразуются; неоднозначные форматы требуют ручного выбора. Сохранённый результат меняется только явным действием.
- Веса будущих дат ограничиваются весом текущего дня, как предусмотрено формулой `max(0, ageDays)`. История сортируется по времени решения и UUID при равенстве времени.

## Проверки

```sh
npm run check
npx playwright install chromium
npm run test:e2e
```

`check` включает строгую типизацию, ESLint, Prettier, 99 компонентных/доменных/интеграционных тестов и production-сборку. Основной браузерный набор содержит 60 проверок, включая офлайн-запуск после закрытия страницы, ввод без сети, перенос Blob через JSON, отмены и неверный импорт.

E2E требует готовый `dist/` и свободные порты 4173/4174. Сервер 4174 отдаёт production-сборку, 4173 — отдельную страницу компонентов. Контексты браузера изолированы, данные опубликованного сайта не затрагиваются. Скриншоты и трассировки ошибок находятся в `test-results/`.

Для отдельного запуска доступны `typecheck`, `lint`, `format:check`, `test`, `build`; `npm run format` форматирует исходники. Браузерные проверки проведены в Chromium на 1440 и 320 px, основные экраны дополнительно проверены на 390, 768 и 1024 px. Firefox, Safari и физические устройства не тестировались.

## Зависимости

React, TypeScript, Vite, Tailwind и Dexie заданы документацией. React Router обеспечивает переходы; Lucide — иконки; Fontsource — локальные шрифты; Tabbable — фокус диалогов; Dexie React Hooks 1.x — реактивные выборки без библиотек совместного редактирования; Zod — строгую проверку JSON. Модуль резервных копий загружается отдельно и входит в офлайн-кеш.

ESLint, JSX a11y, React Hooks, Prettier, Vitest 4, jsdom, Testing Library, fake-indexeddb, Playwright и axe используются для проверок. Версии закреплены lock-файлом.
