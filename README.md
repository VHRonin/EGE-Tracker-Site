# ЕГЭ Трекер

Веб-приложение для самостоятельной подготовки к ЕГЭ по профильной математике, русскому языку и информатике. Записывайте результаты решения заданий, следите за прогрессом и планируйте повторение тем.

**[Открыть ЕГЭ Трекер](https://vhronin.github.io/EGE-Tracker-Site/)**

Приложение работает без регистрации. Данные сохраняются локально в браузере; после первой загрузки и подготовки офлайн-режима можно заниматься без интернета.

## Возможности

- **Три предмета.** Стартовые названия заданий, редактируемые номера и собственные подтемы.
- **Быстрая запись решений.** Достаточно указать правильность; текст задания, ответы, комментарий и скриншот можно добавить по желанию.
- **История практики.** Просмотр и редактирование записей, поиск, фильтры и пакетный ввод результатов.
- **Прогресс и повторение.** Уровень освоения учитывает историю решений, а отдельная очередь помогает выбрать, что пора повторить.
- **Статистика.** Графики, объём практики и точность за выбранный период.
- **Резервные копии.** Экспорт и импорт JSON вместе с историей и изображениями.
- **Установка на устройство.** PWA поддерживает установку средствами совместимых браузеров и работу офлайн.

Оценка освоения помогает ориентироваться в подготовке и не является прогнозом балла ЕГЭ. Приложение предназначено для учёта собственной практики и не содержит банка задач.

## Как начать

1. Откройте сайт и выберите предмет.
2. Выберите номер задания; при необходимости добавьте подтему.
3. Запишите результат решения.
4. Следите за статистикой и рекомендациями по повторению.
5. Регулярно сохраняйте резервную копию в настройках.

Подробнее — в [инструкции пользователя](docs/USER_GUIDE.md).

## Хранение данных

История и скриншоты хранятся в IndexedDB текущего браузера. Приложение не отправляет их на сервер и не синхронизирует между устройствами автоматически.

Для переноса данных на другое устройство или в другой браузер экспортируйте JSON-копию и импортируйте её там. Импорт заменяет текущие данные после проверки и подтверждения; объединение копий не поддерживается.

Очистка данных сайта может удалить историю. Другой адрес сайта, браузер или профиль браузера использует отдельное хранилище — сохраняйте резервные копии заранее.

## Локальный запуск

Нужен Node.js 22.12 или новее; рекомендуемая версия — 24.

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

Для сборки и локального просмотра production-версии:

```sh
npm run build
npm run preview
```

Готовые файлы находятся в `dist/`. Service worker и офлайн-режим включены в production-сборке; для них нужен HTTPS или localhost.

## Технологии и проверки

React, TypeScript, Vite, Tailwind CSS, Dexie.js / IndexedDB, React Router и PWA. Серверная часть и внешняя база данных не требуются.

```sh
# Типизация, линтер, форматирование, тесты и сборка
npm run check

# Браузерные проверки после сборки
npx playwright install chromium
npm run test:e2e

# Проверки размещения в подпапке GitHub Pages
npm run test:pages
```
