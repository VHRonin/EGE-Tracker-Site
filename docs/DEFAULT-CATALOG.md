# Названия заданий по списку пользователя

Источник: `default-exercise-titles.txt`, сохранённый без изменений из вложения «Список всех заданий.txt». Названия, пунктуация и нумерация перенесены буквально; соответствие официальной структуре экзамена не переопределялось.

Стартовый набор: математика — 20 номеров, русский язык — 27, информатика — 27. Источник содержит математический №20 «Свойства чисел.», которого не было в прежнем наборе из 19 номеров.

- Новая база и явный сброс создают каталог с этими названиями.
- Однократное обновление IndexedDB v1 → v2 заменяет только точные шаблоны «Задание №N» для известных номеров; добавляет математический №20, если его ещё нет.
- Пользовательские названия, существующий №20, UUID, история, подтемы и изображения сохраняются. Удалённые старые номера не восстанавливаются. Повторный запуск не повторяет обновление.
- Схема таблиц и формат JSON v1 не меняются. Импорт по-прежнему восстанавливает точное содержимое копии; его названия не переписываются после восстановления.
- Вручную добавляемые номера сохраняют существующий сценарий ввода названия и его запасной шаблон.

Проверки: точное сравнение всех 74 названий с исходным файлом, создание и сброс каталога, миграция с нестандартными UUID предметов, пользовательские названия и номера, сохранность Blob и истории, однократность обновления, прежний формат резервной копии. Браузерная проверка обновляет реальную старую IndexedDB и проверяет историю и экспорт после миграции.
