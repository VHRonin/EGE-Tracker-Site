# Редизайн главной — первый проход

Исторический отчёт первого прохода: фазы A–C из `UI_SPECIFICATION.md`. Пользователь согласовал главную; последующее распространение на все экраны описано в [FULL-REDESIGN.md](FULL-REDESIGN.md).

## Что переиспользовано

- Существующие маршруты, навигация, формы, диалоги, PWA и резервные копии.
- `useProgress`, доменные `reviewPriority`, `dailyStatistics`, `periodRange`.
- Прежние модели, IndexedDB/Dexie v1, правила освоения и повторения, формат JSON v1.
- Компоненты ссылок-кнопок, бейджей и сообщения о загрузке/ошибке.

Главная заменена новой композицией, поскольку меняется вся визуальная иерархия. Новый `useHomeView` только готовит данные для отображения; записей в базу и новых формул оценки в нём нет. Стили оболочки включаются только на маршруте `/` через `.poster-home`.

## Визуальный язык

Токены палитры находятся в `src/styles/poster-home.css`: бумажный фон, чернильный контур, синий/коралловый/фиолетовый предметные акценты и жёлтые стикеры. Заголовки — локальный кириллический Oswald 700; текст — прежний Manrope; короткие рукописные акценты — Caveat. Единственная новая зависимость `@fontsource/oswald` поставляет шрифт локально, без запросов к Google Fonts.

Контрастная типографика, отдельная сюжетная иллюстрация, клетчатая бумага, поля ответов, номерные ярлыки и жёсткие тени используются как единый язык. Данные и заголовки остаются HTML. Цвет правильности дополнен текстом и значками. Увеличение текста поддерживается через rem, переносы и гибкие блоки.

## Происхождение ассетов

- `reference.png`, `DESIGN_SYSTEM.md`, `UI_SPECIFICATION.md` — исходные материалы пользователя, сохранены без изменений. Референс не используется как экран или фон приложения.
- `public/illustrations/study-evening.webp` — оригинальная иллюстрация, созданная генератором изображений для этого проекта: вечерняя подготовка за столом, город за окном. PNG перекодирован в WebP без изменения композиции. Текст интерфейса в изображении отсутствует.
- `math.svg`, `russian.svg`, `informatics.svg`, `mountain.svg` — оригинальные SVG, нарисованные программно для этого проекта.
- `paper-grain.svg` — программная бумажная фактура SVG.
- Иконки — существующая зависимость Lucide. Шрифты — локальные пакеты Fontsource, лицензии включены в зависимости.

Временных картинок и мест, требующих обязательной ручной замены иллюстратором, нет. Художественное направление и соответствие ожиданиям оценивает пользователь на этом согласовании.

## Проверки

- `npm run check`: строгие типы, ESLint, Prettier, 95 модульных тестов, production-сборка.
- Playwright: 54 проверки, включая прежние сценарии и новую главную; desktop и mobile.
- Пустая и заполненная история, локальная дата последнего решения через границу UTC-суток, точность и 7 календарных дней без фиктивных значений.
- Ширины 320/360/390/430/768/1024/1440 px; текст 100% и 200%; отсутствие глобальной горизонтальной прокрутки и переполнения смысловых блоков.
- Axe WCAG A/AA, клавиатурные переходы, уменьшение движения, загрузка только локальных ресурсов.
- Офлайн-загрузка главной, иллюстраций и данных; прежние проверки сохранения, скриншотов решений, экспорта/импорта и работы без сети.

Доменные, прикладные и хранилищные модули не изменены. Конфликт старого минималистичного направления с новым плакатным разрешён явно в разделе 0 новой UI-спецификации: визуальные требования редизайна имеют приоритет, функциональные требования исходных документов сохраняются.
